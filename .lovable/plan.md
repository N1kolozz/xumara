

## Complete Migration Plan: Independence from Lovable Cloud

### **Phase 1: Set Up Your Own Supabase Project** (15 minutes)

1. **Create Supabase account and project:**
   - Go to https://supabase.com and sign up
   - Create a new project (choose region close to Georgia/Europe)
   - Wait for project provisioning (~2 minutes)

2. **Save your credentials:**
   - Go to Project Settings → API
   - Copy and save:
     - Project URL (looks like: `https://xxxxx.supabase.co`)
     - `anon` public key (long JWT token)
     - `service_role` key (keep this SECRET!)

### **Phase 2: Create Database Schema** (10 minutes)

1. **Open SQL Editor in your Supabase dashboard:**
   - Click "SQL Editor" in left sidebar
   - Click "New Query"

2. **Run the complete schema script:**
   - Copy the entire SQL script I provided above (the one with tables, RLS policies, and realtime configuration)
   - Paste it into the SQL Editor
   - Click "Run" button
   - Verify all tables were created successfully (you should see 6 tables in Table Editor)

### **Phase 3: Import Your Game Cards Data** (5 minutes)

Your database has **101 Georgian language game cards** that need to be migrated. I'll prepare an INSERT script for all your cards.

1. **Export cards from Lovable Cloud:**
   - I'll provide you with a complete SQL INSERT script containing all 101 cards with their Georgian text

2. **Import into your Supabase:**
   - Run the INSERT script in your SQL Editor
   - Verify cards were imported: `SELECT COUNT(*) FROM cards;` should return 101

### **Phase 4: Clone and Configure Your Local Project** (10 minutes)

1. **Connect GitHub (if not already done):**
   - In Lovable, click the GitHub icon in top-right
   - Transfer your project to GitHub repository

2. **Clone to your local machine:**
   ```bash
   git clone <your-github-repo-url>
   cd <your-project-folder>
   ```

3. **Install dependencies:**
   ```bash
   npm install
   # or
   bun install
   ```

4. **Create .env.local file:**
   ```bash
   touch .env.local
   ```

5. **Configure environment variables:**
   Edit `.env.local` and add:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=your-anon-key-here
   VITE_SUPABASE_PROJECT_ID=your-project-id
   ```

   ⚠️ **IMPORTANT:** Use `.env.local` (NOT `.env`) because:
   - `.env` is already used by Lovable Cloud
   - `.env.local` is in `.gitignore` and won't be committed
   - Local environment files take precedence

### **Phase 5: Update Supabase Client Configuration** (5 minutes)

You need to modify the Supabase client to use your new environment variables:

**Edit `src/integrations/supabase/client.ts`:**
```typescript
import { createClient } from '@supabase/supabase-js';
import type { Database } from './types';

// Use .env.local variables for local development
const SUPABASE_URL = import.meta.env.VITE_SUPABASE_URL;
const SUPABASE_PUBLISHABLE_KEY = import.meta.env.VITE_SUPABASE_PUBLISHABLE_KEY;

if (!SUPABASE_URL || !SUPABASE_PUBLISHABLE_KEY) {
  throw new Error('Missing Supabase environment variables. Check your .env.local file.');
}

export const supabase = createClient<Database>(SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY, {
  auth: {
    storage: localStorage,
    persistSession: true,
    autoRefreshToken: true,
  }
});
```

### **Phase 6: Update Supabase Types** (5 minutes)

Your `src/integrations/supabase/types.ts` file is auto-generated by Lovable. You need to regenerate it for your new Supabase project:

1. **Install Supabase CLI:**
   ```bash
   npm install -g supabase
   ```

2. **Login to Supabase:**
   ```bash
   supabase login
   ```

3. **Link your project:**
   ```bash
   supabase link --project-ref your-project-id
   ```

4. **Generate TypeScript types:**
   ```bash
   supabase gen types typescript --linked > src/integrations/supabase/types.ts
   ```

### **Phase 8: Deploy Independently** (Optional)

Once everything works locally, you can deploy to:

**Option A: Vercel (Recommended - Free)**
1. Install Vercel CLI: `npm install -g vercel`
2. Run: `vercel`
3. Add environment variables in Vercel dashboard
4. Deploy: `vercel --prod`

**Option B: Netlify (Free)**
1. Install Netlify CLI: `npm install -g netlify-cli`
2. Run: `netlify init`
3. Configure build settings
4. Deploy: `netlify deploy --prod`

**Option C: Your own VPS/Server**
1. Build: `npm run build`
2. Upload `dist/` folder to your server
3. Configure nginx/apache to serve the static files
